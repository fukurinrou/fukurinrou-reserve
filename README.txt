福林楼「席・コース予約」サイトに、予約受付停止日の判定を追加する更新です。

先にすること（初回のみ）
Cloudflare D1 データベース「fukurinrou-osechi-db」のコンソールで、
このフォルダ内の「D1_予約受付カレンダー設定.sql」を実行してください。

GitHub へ入れるもの
このフォルダの「src」「public」と「schema.sql」を、
GitHub の「fukurinrou-reserve」リポジトリの一番上に上書きアップロードしてください。

確認方法
管理画面で受付停止にした日付を選んだ場合は、予約フォームに案内が出て予約できません。
また、直接送信された場合もサーバー側で受付停止日を拒否します。
